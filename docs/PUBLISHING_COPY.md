### Full description

Summit is the mobile cockpit for your self-hosted AI agent.

If you already run Hermes, Summit gives it a first-class mobile surface: pair with a 6-digit code,
send messages from your phone, read streaming markdown cleanly, see agent status, and respond to
blocking approve or stop decisions without returning to your desktop.

Summit is built for technical users who already run their own agent infrastructure. The default
relay flow uses a small connector next to your agent. The connector dials out to the Summit relay,
so your phone can reach your agent from anywhere without exposing your home server. Your Hermes API
key stays on your server; your phone stores only a relay device token.

What Summit supports:

- Pair a Hermes agent with a short code
- Chat from iPhone with streamed responses
- Read markdown, code blocks, tables, and structured output
- See whether your agent is idle, running, blocked, or disconnected
- Approve or stop supported Hermes runs
- Reopen recent chats
- Use direct mode for advanced host-and-key setups

Summit is not a consumer chatbot. It is a mobile control surface for people who already run
self-hosted agents and want a better way to work with them away from the desk.

## Privacy Copy

### Short version

In relay mode, your Hermes API key stays on your server. Summit stores a relay device token on your
phone so it can connect to your paired agent.

### Store-friendly version

Summit is built for self-hosted agent users who care where credentials live. In relay mode, the
connector runs next to your agent and keeps the Hermes API key on your server. Your phone stores a
relay device token used to reach your paired agent.

### Telemetry version

Summit may collect minimal operational telemetry to understand pairing, relay reliability, crashes,
and feature failures. Summit does not collect message content, agent responses, API keys, pairing
codes, host URLs, cron output, screenshots, or session replays.

### Trust caveat

Summit's hosted relay forwards traffic in flight over TLS. It is not end-to-end encrypted in v1.
Users who do not want a hosted relay can use direct mode with their own reachable host or tunnel.

## FAQ Copy

### Is Summit an AI assistant?

No. Summit is a mobile client for AI agents you already run yourself.

### Which agents does Summit support?

The first version focuses on Hermes. Other agent frameworks may come later once their control and
approval APIs are mature enough for the same mobile flow.

### Does Summit store my Hermes API key?

In relay mode, no. The Hermes API key stays on the server with the connector. Your phone stores a
relay device token. In direct mode, the API key is stored locally in the iOS Keychain.

### Do I need to expose my server?

Not in relay mode. The connector dials outbound to the Summit relay. Direct mode is available for
users who already have a reachable host, tunnel, or VPN.

### Is the relay end-to-end encrypted?

Not in v1. Traffic uses TLS to the relay, and the relay forwards messages between the app and
connector. End-to-end encryption is a later upgrade candidate.

### Is OpenClaw supported?

Not in v1. Summit starts with Hermes because Hermes exposes the APIs needed for chat, status, and
approve/stop controls.
