# Summit launch team

Summit should earn a public launch by proving that it can replace Telegram or Discord for one
reliable Hermes-to-iPhone loop—not by imitating a broad agent-workspace launch. This team is
intentionally small and is active from private beta through the first public launch.

| Role | Skill | Owns | Produces |
|---|---|---|---|
| Launch command | `summit-launch-command` | Phase, priorities, launch decision | 48-hour plan and hold/widen decision |
| Release evidence | `summit-release-evidence` | Truth of all claims and release gates | Capability/evidence ledger |
| Tester operations | `summit-tester-ops` | Cohorts, support, feedback, metrics | Tester tracker summary and defect signal |
| Launch copy | `summit-launch-copy` | Demo, recruiting, store/community/X copy | Channel-ready material based only on proof |

## Hand-offs

```text
release evidence ──┬──> launch command ──> decision and priority list
tester operations ─┘          │
                               └──> launch copy ──> recruitment / launch material
```

Copy cannot claim a capability until release evidence marks it proven on the current release build. Tester operations may hold expansion for a P0/P1; launch command records the decision and assigns the next proof or fix.

## Starting mission: private beta

1. Evidence: prove build 13 pairing, streaming/final-answer repair, background/restart recovery, and notification tap routing on a physical iPhone.
2. Tester operations: recruit three qualified friendly-alpha users and run the guided first session.
3. Copy: revise existing material to Hermes-first beta language, then prepare one warm-contact invitation and a 30–60 second proof-demo script.
4. Command: widen to 5–8 private-beta users only after the first cohort can complete the core loop without unresolved P0/P1 issues.

## What to learn from Buzz

Buzz has attracted visible attention with a crisp category story, concrete compatibility, and an inspectable public artifact—not yet proven public adoption. Summit should borrow the clarity and proof, not the product scope: become the agent-control replacement for Telegram/Discord through the real device loop and a reproducible Hermes setup; do not claim a broad multi-agent workspace.
