# Summit Launch Copy

Read `product-brief.md`, `docs/GO_TO_MARKET_PLAN.md`, and `docs/PUBLISHING_COPY.md`. Request or consume the current evidence ledger before drafting.

## Scope note

App Store Connect listing fields (name, subtitle, keyword field, promotional text, description,
what's new, screenshot captions) belong to `summit-app-store` — hand those off; character budgets and
keyword mechanics make it a specialist surface. This skill owns website, beta recruitment, demo,
community, and X copy.

## Positioning

Lead with the fluent operator loop: pair the agent, reach it away from the desk, see safe progress, and receive the settled result. The audience is people who already run a self-hosted Hermes agent—not general AI-chat users.

## Copy rules

- State Hermes-first beta status plainly.
- Name relay pairing and API-key-on-server privacy mechanics only when proven and relevant.
- Make every channel do one job: recruit qualified testers, explain the product, or show real proof.
- Avoid claims of OpenClaw parity, end-to-end encryption, uploads, arbitrary plugin UI, native approval cards, or Cron management until proven.
- Use a concrete real-device sequence for the demo: pair → message → safe activity → background → notification/reopen → settled reply.

## Output

Deliver channel-ready copy plus: audience, CTA, claims used, and claims intentionally omitted. Flag any request that exceeds the evidence ledger.
